In this folder contains the Lost and Found app and also it with the Google Maps all in one folder. This App allows you to create adverts for lost and found items so you can keep track of your lost items if you can't find them when creating the advert you put several things like an image and Location and other things. It also allows you to show all your Lost and Foudn Items on a dashbord also be able to remove them from their once found. Be able to show on a map all your items from the main screen which will then take you to antoher screen with a full screen map.
The XML files in this folder are the Create a new advert xml which is the layout on how you fill in a form that conatins the title, phone, description, date location, also image as well. The Main xml is is the homepage and main screen and has the button to create a new advert and show the items on map and to also show all your lost and found items. The remove item xml allows you to remove an item. The Show all lost and found xml shows a dashboard with all the Lost and found items with several buttons and a search bar and some filter buttons. The Last screen is the Maps 1 xml and this is the Google Maps where you can see all your items.
The Create a New Advert Class is where all the code is for the create a new advert and this code contains all the code to make that screen work. The Item Dao contains some functions for the app like to delete and update and select all items and order them for timestamp in different orders asscending or desscending. Items Class Contains all the things to make when creating the advert to taking in all the things the user has inputted. Items Adapter is for the list view to make that work. Main Activity Class is code to make the main screen work so code for all of the buttons to go to different screens and other things. The Maps Class has the code to make the Google Maps work. Remove Item class has code to be able to remove items from the app like the found items. Room DB class contains all the information for the Room Database and how it works. The last class show all lost and found items where it contains code for the buttons and for the list to work and other things.
